# Webhook test fixtures

`github/`: sample deliveries from [octokit/webhooks](https://github.com/octokit/webhooks),
`payload-examples/api.github.com`, branch `main`, fetched 2026-11-04, unchanged. Licence: MIT, Copyright (c) 2018 Gregor Martynus.
File names are `<event>.<action>.json`, or `<event>.json` when the event has no action.

`slack/`: written for these tests in the shape of the Slack API reference for incoming
webhooks (`text`, legacy `attachments`, Block Kit `blocks`). Names and addresses are made up.
