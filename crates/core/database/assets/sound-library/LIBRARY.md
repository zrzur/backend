# Sound library

Ready-made soundboard sounds a server can add. Every sound comes from a Kenney pack
(kenney.nl), released under **CC0 1.0** (public domain); each pack's own License.txt is in
`licenses/`. The sounds were made louder or softer towards one loudness (mean -20 dB, peak
limited at -1 dBFS) and re-encoded as Ogg Vorbis. Voice lines are English recordings.
