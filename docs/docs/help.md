# Helping Zrzur

You can contribute to Zrzur in several ways:

### 1. Feedback

Open issues on the relevant Zrzur GitHub repositories under [github.com/zrzur](https://github.com/zrzur) once those repositories are published. Until then, treat this workspace as private development.

### 2. Translate

Localization for the web client lives in the Zrzur Web tree (Lingui catalogs). Contribute translation updates through pull requests on the web repository when it is public. A separate Weblate instance for Zrzur is **not** available yet.

### 3. Code

Follow the contribution notes in each component README (`backend`, `web`, `desktop`). Preserve AGPL attribution and keep changes focused.

### 4. Upstream project

Zrzur is independently developed from [Stoat](https://github.com/stoatchat). Upstream contribution channels belong to Stoat and are not Zrzur support destinations.
