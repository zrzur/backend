# Contribution guide

This guide is for developers working on **Zrzur** (backend and related components).

## Expectations

- Keep changes focused and reviewable.
- Preserve AGPL and other license obligations; do not strip copyright notices.
- Prefer Issues/PRs on [github.com/zrzur](https://github.com/zrzur) repositories once published.
- Do not treat Stoat invite links or Stoat support channels as Zrzur support.

## Getting started

- Backend: see the repository [README](https://github.com/zrzur/backend) (publication may be pending) and local `README.md`.
- Web: Zrzur Web tree / upstream provenance at https://github.com/stoatchat/for-web
- Desktop: Zrzur Desktop tree / upstream provenance at https://github.com/stoatchat/for-desktop

Android and other mobile clients are **out of current Zrzur 26 scope** unless separately approved.
