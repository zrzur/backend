# Security policy

## Report a problem privately

If you find a security problem in Zrzur, report it privately. Do not open a public issue, discussion or pull request.

- **On GitHub:** [report a vulnerability](https://github.com/zrzur/backend/security/advisories/new) in this repository (Security tab, "Report a vulnerability").
- **By email:** **security@zrzur.com**

You can write in English, Arabic or German.

## What to include

- What you found, where, and how to reproduce it.
- What an attacker could do with it.
- Do not include other people's personal data. Use your own test account.

## Supported versions

| Version | Security fixes |
| --- | :---: |
| Latest release (`main`) | Yes |
| `beta` | Yes, fixes land here first |
| Older releases | No, please update |

## What happens next

Zrzur is a volunteer project, built alongside work and school. We try to confirm your report within a few days, but it can take longer. We will tell you what we decide, and credit you when the fix is published, unless you prefer not to be named.

Please give us a reasonable time to fix the problem before you publish anything about it.

## Rules for testing

- Only test against your own accounts and data, or against your own instance from [zrzur/self-hosted](https://github.com/zrzur/self-hosted).
- Do not disrupt the service: no denial-of-service, load or spam testing.
- Do not access, change or delete data that is not yours. If you reach someone else's data by accident, stop and tell us.
- No social engineering or phishing of Zrzur users or staff.

If you act in good faith and follow these rules, we treat your report as help, not as an attack.

## Out of scope

- Instances of Zrzur run by other people: report to whoever runs them.
- Reports from automated scanners with no proof of an actual problem.
- Problems in third-party services, unless Zrzur uses them in an unsafe way.

Zrzur is not affiliated with Stoat or Revolt. Please do not send Zrzur reports to the Stoat team.
